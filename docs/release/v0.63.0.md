# v0.63.0: Exception Review Links

The container scan blocked publication of this tag after detecting a vulnerable Debian `zlib1g` package. See [v0.63.1](v0.63.1.md) for the patched release.

Reviewers can now send a colleague directly to the exception that needs attention. The link opens that issue with its current evidence and resolution history, even if the issue is closed or outside the recipient's queue filters.

## What’s new

- **Copy review link** in the connected Exception Desk, with a selectable URL when clipboard access is unavailable.
- A single-issue view that lets authorized reviewers inspect evidence, read history, and save resolutions. **Back to exception queue** restores their remembered filters and protects unfinished notes.
- An additive `GET /api/v1/quarantine/{quarantine_id}` endpoint protected by organization access and `validation:write`. The link contains only the exception UUID as a URL fragment.

## Try it

Start the updated local demo with `python3 scripts/demo.py` (use `python` on Windows), choose **Exceptions**, and select **Copy review link** on a record. Open it in a second tab. Links work against the same connected instance and database. If the workspace defaults to another organization, select the organization that owns the issue.

No database migration is required. The public GitHub Pages demo remains a static synthetic preview. See the [Exception Desk guide](https://imtiazither.github.io/eduwork-databridge/docs/guides/exception-desk/) for the connected workflow.

## Release checks

Coverage includes tenant isolation, viewer denial, closed-issue lookup, manual link copying, desktop and mobile navigation, and draft protection. The release workflow regenerates backup/restore evidence for the tagged version before publishing downloads.
