# v0.20.0: Match Review Queue

Released: 2026-09-08

v0.20.0 turns individual match decisions into a manageable review workflow. Authorized reviewers can find candidates that need attention, filter the queue by current status, page through larger queues, inspect the latest decision, and see how much work remains.

## Added

- `GET /api/v1/matches/review-queue` with status filtering, bounded `limit`, and `offset` pagination
- `GET /api/v1/matches/review-queue/summary` with total, unreviewed, and status counts
- Latest-decision and decision-count context for every queue item
- Integration coverage for authorization, filtering, pagination, decision history, and summary updates

## Changed

- Updated Python, API, frontend, package, and documentation versions to `0.20.0`
- Updated Vitest to `5.0.0` to resolve the latest dependency advisory
- Reframed public project language around capabilities, evidence, and responsible use
- Removed old public status labels from project materials

## Responsible-use boundary

Public examples use deterministic synthetic data. Match suggestions and review states are decision-support evidence; people remain responsible for consequential decisions.
