# v0.61.0: One-Command Demo

Date: 2026-10-18

This update helps first-time users and organizational evaluators get from a downloaded repository to a working, connected demonstration with fewer setup steps.

## Added

- A read-only setup checker with clear remedies for missing or unsupported Python, uv, Node/npm, incomplete checkouts, and occupied ports
- `python3 scripts/demo.py` to install locked dependencies, prepare synthetic data, start both servers, and open the reviewer screen after readiness checks
- Automatic free-port selection, loopback-only servers, per-workspace logs, and cleanup on shutdown or startup failure
- A separate SQLite demo database and artifact directories under `var/demos/quickstart/`, independent of normal application database settings
- Saved review history preserved across restarts; initial preparation is not repeated unnecessarily
- A confirmed `--reset` workflow, ownership markers, workspace locks, and symlink/path checks that refuse unrelated or active directories
- Automated desktop/mobile browser journeys that save an exception resolution, reload its history, and verify viewer restrictions
- A dedicated CI browser job with screenshots, failure traces, and a report artifact
- A beginner guide with installation links, a five-minute walkthrough, safe reset, and troubleshooting

## Try it

Install Python 3.12 or 3.13, uv, and Node.js 24 LTS. Open the repository folder in a terminal, then run:

```bash
python3 scripts/demo.py
```

On Windows use `python`. No Docker, GitHub login, company database, or personal records are needed. The first dependency download can take several minutes. Follow the printed local URL, choose **Exceptions**, save a note, and reload to revisit its history. Press Ctrl+C to stop. See the [complete beginner guide](https://imtiazither.github.io/eduwork-databridge/docs/guides/demo-quickstart/).

To check the machine without changing it, run `python3 scripts/demo_doctor.py`. To discard only the synthetic workspace and reload the case, run `python3 scripts/demo.py --reset` and type the requested confirmation.

## Upgrade and Scope

No new database migration or API contract change is introduced. Existing application databases are not selected by this quickstart. Continue using the normal deployment process for those databases. Keep real company, student, and employee data out of this fictional-data demo.

The public GitHub Pages example remains non-persistent. The connected local demo saves human review outcomes; those outcomes do not independently correct source records or approve them for publication. This launcher is for local evaluation, not an organizational deployment installer.
