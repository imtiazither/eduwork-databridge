# v0.63.1: Exception Review Links

Reviewers can now send a colleague directly to the exception that needs attention. The link opens that issue with its current evidence and resolution history, even if the issue is closed or outside the recipient's queue filters.

## What’s new

- **Copy review link** in the connected Exception Desk, with a selectable URL when clipboard access is unavailable.
- A single-issue view lets authorized reviewers inspect evidence, read history, and save resolutions. **Back to exception queue** restores remembered filters and protects unfinished notes.
- An additive `GET /api/v1/quarantine/{quarantine_id}` endpoint protected by organization access and `validation:write`. The link contains the exception UUID as a URL fragment.

## Container security fix

The v0.63.0 tag passed CI and the Compose smoke test. Its release was blocked by the container scan for CVE-2026-85091. This patch version upgrades the API container's `zlib1g` runtime to a Debian security-fixed version. The Docker build checks the minimum fixed package version. See the [Debian security advisory](https://security-tracker.debian.org/tracker/DSA-6613-1).

## Try it

Start the updated local demo with `python3 scripts/demo.py` (use `python` on Windows), choose **Exceptions**, and select **Copy review link** on a record. Open it in a second tab. Links work against the same connected instance and database. If the workspace defaults to another organization, select the organization that owns the issue.

No database migration is required. The public GitHub Pages demo remains a static synthetic preview. See the [Exception Desk guide](https://imtiazither.github.io/eduwork-databridge/docs/guides/exception-desk/) for the connected workflow.

## Release checks

The regression suite covers organization isolation, viewer denial, closed-issue lookup, manual link copying, desktop and mobile navigation, and draft protection. For this tag the release workflow rebuilds the API container, checks it with Trivy, verifies the image signature, and generates fresh package and backup/restore evidence.
